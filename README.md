# Thread Synchronization Visualizer

## About the Project
Thread Synchronization Visualizer is a web-based educational project that demonstrates how thread synchronization works in Operating Systems. It helps users understand how multiple threads access shared resources and how synchronization techniques prevent race conditions.

## Features
- **Unsynchronized Execution:** Demonstrates how race conditions can occur when multiple threads access shared resources without synchronization.
- **Mutex:** Shows how mutual exclusion allows only one thread at a time to access a critical section.
- **Semaphore:** Demonstrates how access to shared resources can be controlled using permits.
- **Monitor:** Explains synchronized access to shared resources using monitor-based concepts.

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
The main objective of this project is to make Operating System thread synchronization concepts easier to understand through interactive visual demonstrations.

## How to Run
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Explore the available synchronization methods.

## Learning Outcomes
- Understanding thread synchronization.
- Learning about critical sections and race conditions.
- Comparing synchronized and unsynchronized execution.
- Understanding Mutex, Semaphore, and Monitor concepts.
